Spacefacts Pipeline

This is a personal, single-user automation tool. It generates short video content and uploads it to a YouTube channel that I personally own and operate. It does not access, read, or share any other person's data or account.

The tool uses the YouTube Data API solely to upload videos to my own channel and to manage their visibility (private/unlisted/public) from a personal review dashboard that only I can access.

See the Privacy Policy for details on what data this app touches.
