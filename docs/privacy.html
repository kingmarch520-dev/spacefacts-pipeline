Privacy Policy

Last updated: 2026

What this app is

Spacefacts Pipeline is a personal automation project. It is not a public product or service — it is used only by its owner to generate and upload video content to a single, personally-owned YouTube channel.

What data it accesses

This app requests access to the YouTube Data API solely to:

  • Upload video files to the owner's own YouTube channel
  • Change the privacy status (private/unlisted/public) of videos it uploaded
  • Delete videos it uploaded, if rejected during review

It does not access any other user's YouTube account, videos, comments, subscriptions, or personal information. It does not collect, store, sell, or share data with any third party.

Data storage

Video metadata (title, description, YouTube video ID, thumbnail link, review status) is stored in a private database accessible only to the app owner, used solely to power a personal review dashboard.

Contact

Questions about this app or policy can be directed to the project owner via the GitHub repository this page is hosted from.
